===

```
Create : 2025-04-25
```

# 目的

GPT等の外部AIにMYNT MIDI文字列フォーマットで作曲させ、
そのテキスト出力をそのままMYNT MIDIエディタに貼り付けて再生・編集できるようにする。


# 現状の課題

MYNT MIDIの文字列記法はAI連携に向いている部分と向いていない部分がある。

## 向いている点

- テキストベースなのでLLMが直接生成できる
- 記法がシンプル（T, O, V, 音名, S, ~, [] の7種類のみ）
- MSX BASIC PLAY文に似た直感的な構文

## 向いていない点

- 仕様がMYNT MIDI独自であり、AIの学習データに含まれていない
- テンポ値が「BPM」ではなく「音の長さを制御する値」として使われており、音楽的な意味と乖離がある
- 音符の長さ（4分音符・8分音符等）の概念がなく、テンポ変更で長さを表現する
- 休符の長さもテンポに依存するため、リズムパターンの記述が直感的でない
- 和音内でオクターブを毎回指定する必要があり冗長


# 提案

## 提案1: AIプロンプトテンプレートの整備（システム変更なし）

現在の記法をそのまま使い、AIに正しく出力させるためのプロンプトを用意する。

### プロンプトに含めるべき内容

1. MIDI文字列の完全な文法仕様（docs/midi-string-spec.md の内容を要約）
2. トークンの一覧と意味
3. テンポ値と実際の音の長さの対応表
4. サンプル楽曲とその解説
5. 出力フォーマットの指定（MIDI文字列のみ、説明不要）

### プロンプト例

```
あなたはMYNT MIDI形式の作曲AIです。以下の記法に従ってMIDI文字列を出力してください。

## 記法ルール
- T{数値}: テンポ。1音の長さ(秒) = 60 / T値。T120=0.5秒, T240=0.25秒, T480=0.125秒
- O{数値}: オクターブ(0-10)。O5が中央付近
- V{数値}: 音量(デフォルト50)
- C,D,E,F,G,A,B: 音名（ドレミファソラシ）
- 音名+: シャープ（例: C+ = ド#）
- 音名-: フラット（例: D- = レ♭）
- S: 休符（現在のテンポ分の無音）
- ~: フェードアウト
- [{音符列}]: 和音（例: [O4CO4EO4G] = ドミソ）
- スペースは無視される（可読性のために使用可）

## テンポと音符の長さの対応（BPM120基準）
- 全音符: T30
- 2分音符: T60
- 4分音符: T120
- 8分音符: T240
- 16分音符: T480
- 3連符: T360

## 重要な注意
- テンポ変更は以降の全ての音符に影響する（音符の長さを変えたい場合はTを変更する）
- オクターブ変更も以降の全ての音符に影響する
- 和音内ではO指定が必須（外側のOは和音内に引き継がれない）

## サンプル
コイン音: T600O6BT100O7E~
1upサウンド: T450O7EGO8ECDG
ドミソ和音: T120[O4CO4EO4G]

## 出力形式
MIDI文字列のみを出力してください。説明は不要です。
```

### メリット
- システム変更が不要
- すぐに試せる
- AIの出力をそのままtextareaに貼り付けるだけ

### デメリット
- AIが記法を間違える可能性がある（特にテンポ値の計算）
- 長い楽曲ではAIの出力が不安定になりやすい
- プロンプトが長くなるとコンテキストを圧迫する


## 提案2: 中間フォーマット（JSON）の導入

AIにはより直感的なJSON形式で出力させ、MYNT MIDI側でMIDI文字列に変換する。

### JSON形式の定義

```json
{
  "bpm": 120,
  "notes": [
    { "pitch": "C4", "duration": "4n" },
    { "pitch": "E4", "duration": "4n" },
    { "pitch": "G4", "duration": "4n" },
    { "pitch": ["C4", "E4", "G4"], "duration": "4n" },
    { "pitch": "rest", "duration": "4n" },
    { "pitch": "C5", "duration": "8n", "velocity": 80 },
    { "pitch": "fade", "duration": "4n" }
  ]
}
```

### フィールド定義

| フィールド | 型 | 説明 |
|---|---|---|
| bpm | number | 曲全体の基本テンポ（BPM） |
| notes | array | 音符の配列（時系列順） |
| notes[].pitch | string / string[] | 音名+オクターブ（例: "C4", "F#5"）。"rest"=休符, "fade"=フェードアウト。配列で和音 |
| notes[].duration | string | 音符の長さ。"1n"=全音符, "2n"=2分, "4n"=4分, "8n"=8分, "16n"=16分, "4t"=3連符 |
| notes[].velocity | number (optional) | 音量（0-127、MIDI標準に準拠。省略時64） |

### pitch の記法

- `C4` = ド（オクターブ4）→ MYNT MIDI の `O4C`
- `F#5` = ファ#（オクターブ5）→ MYNT MIDI の `O5F+`
- `Bb3` = シ♭（オクターブ3）→ MYNT MIDI の `O3B-`
- `rest` = 休符 → MYNT MIDI の `S`
- `fade` = フェードアウト → MYNT MIDI の `~`

### duration → テンポ値の変換

BPMを基準に、duration文字列をMYNT MIDIのT値に変換する。

```
T値 = BPM × (duration の分母 / 4)
```

| duration | 意味 | BPM120でのT値 | 1音の長さ |
|---|---|---|---|
| "1n" | 全音符 | T30 | 2.0秒 |
| "2n" | 2分音符 | T60 | 1.0秒 |
| "4n" | 4分音符 | T120 | 0.5秒 |
| "8n" | 8分音符 | T240 | 0.25秒 |
| "16n" | 16分音符 | T480 | 0.125秒 |
| "4t" | 4分3連符 | T360 | 0.167秒 |
| "2n." | 付点2分音符 | — | 後述 |

### 付点音符の扱い

付点音符は元の長さの1.5倍。MYNT MIDIには直接対応するトークンがないため、
変換時にT値を調整する。

```
付点のT値 = 元のT値 / 1.5
```

例: 付点4分音符（BPM120）→ T80（0.75秒）

### 必要な実装

1. `src/js/midi/json-converter.js` — JSON → MIDI文字列の変換モジュール
2. UIにJSON入力用のインターフェース（テキストエリアまたはファイルアップロード）

### メリット
- AIが標準的な音楽記法（C4, 4n等）で出力できるため精度が高い
- GPT, Claude, Gemini等ほぼ全てのLLMがJSON出力に対応
- バリデーションが容易（JSONスキーマで検証可能）
- 他のツールとの相互運用性が高い

### デメリット
- 変換モジュールの実装が必要
- MYNT MIDI固有の超高速テンポ（T3000, T4000等）の表現が難しい
  → 対策: duration に数値（ミリ秒）も許容する（例: `"duration": 20` = 20ms）


## 提案3: AIインポート機能のUI統合

提案2のJSON変換に加え、AI連携をUIに組み込む。

### UI案

1. ヘッダーに「AI作曲」ボタンを追加
2. クリックするとモーダルが開く
3. モーダル内に:
   - テキスト入力欄（AIへの指示: 「明るいファンファーレ」「コイン取得音」等）
   - API設定（APIキー、モデル選択）
   - 「生成」ボタン
4. AIのレスポンス（JSON）を自動変換してtextareaに挿入
5. エディタに自動反映

### 必要な実装

1. JSON変換モジュール（提案2と同じ）
2. AI API呼び出しモジュール（OpenAI / Anthropic / Google AI対応）
3. モーダルUI
4. APIキーのローカルストレージ保存

### メリット
- ユーザーが自然言語で指示するだけで作曲できる
- コピペ不要のシームレスな体験

### デメリット
- 実装コストが大きい
- APIキーの管理が必要（セキュリティ考慮）
- 外部API依存

明示的なImport/Exportボタンによる操作を採用した。

# AI用プロンプトテンプレート

以下のプロンプトをGPT、Claude、Gemini等に渡すことで、
MYNT MIDIにインポート可能なJSONを出力させることができる。

## JSON出力用プロンプト（推奨）

```
あなたは作曲AIです。以下のJSON形式で楽曲データを出力してください。

## 出力フォーマット

{
  "bpm": 120,
  "notes": [
    { "pitch": "C4", "duration": "4n" },
    { "pitch": "rest", "duration": "8n" },
    { "pitch": ["C4", "E4", "G4"], "duration": "4n" }
  ]
}

## フィールド仕様

### bpm (必須)
曲のテンポ。BPM（Beats Per Minute）で指定。

### notes (必須)
音符の配列。時系列順に並べる。

### notes[].pitch (必須)
- 単音: "C4", "F#5", "Bb3" のように 音名 + オクターブ番号 で指定
  - 音名: C, D, E, F, G, A, B
  - シャープ: # を付ける（例: "C#4", "F#5"）
  - フラット: b を付ける（例: "Bb3", "Eb4"）
  - オクターブ: 0〜10（4が中央付近、ピアノの中央ドは C4）
- 和音: 配列で指定（例: ["C4", "E4", "G4"] = ドミソ）
- 休符: "rest"
- フェードアウト: "fade"

### notes[].duration (必須)
音符の長さを指定。
- "1n": 全音符
- "2n": 2分音符
- "4n": 4分音符
- "8n": 8分音符
- "16n": 16分音符
- "4t": 4分3連符
- 付点音符: 末尾に . を付ける（例: "2n." = 付点2分音符, "4n." = 付点4分音符）
- 数値(ミリ秒): 超短い音（効果音用）は数値で直接指定（例: 20 = 20ミリ秒）

### notes[].velocity (任意)
音量。0〜127（MIDI標準）。省略時は64（中程度）。

## 出力ルール
- JSONのみを出力してください。説明文は不要です。
- notes配列は再生順に並べてください。
- 和音は同時に鳴る音をpitch配列にまとめてください。
- 休符は明示的に "rest" で記述してください（暗黙の休符はありません）。

## サンプル

### コイン取得音
{
  "bpm": 120,
  "notes": [
    { "pitch": "B6", "duration": 100 },
    { "pitch": "E7", "duration": "2n" },
    { "pitch": "fade", "duration": "2n" }
  ]
}

### 1upサウンド
{
  "bpm": 120,
  "notes": [
    { "pitch": "E7", "duration": 133 },
    { "pitch": "G7", "duration": 133 },
    { "pitch": "E8", "duration": 133 },
    { "pitch": "C8", "duration": 133 },
    { "pitch": "D8", "duration": 133 },
    { "pitch": "G8", "duration": 133 }
  ]
}

### 簡単なメロディ（きらきら星の冒頭）
{
  "bpm": 120,
  "notes": [
    { "pitch": "C4", "duration": "4n" },
    { "pitch": "C4", "duration": "4n" },
    { "pitch": "G4", "duration": "4n" },
    { "pitch": "G4", "duration": "4n" },
    { "pitch": "A4", "duration": "4n" },
    { "pitch": "A4", "duration": "4n" },
    { "pitch": "G4", "duration": "2n" }
  ]
}

### 和音進行（C → F → G → C）
{
  "bpm": 100,
  "notes": [
    { "pitch": ["C4", "E4", "G4"], "duration": "2n" },
    { "pitch": ["F4", "A4", "C5"], "duration": "2n" },
    { "pitch": ["G4", "B4", "D5"], "duration": "2n" },
    { "pitch": ["C4", "E4", "G4"], "duration": "2n" }
  ]
}
```

# 今後の拡張案

## 音符の長さ指定トークン（L）の追加

現在はテンポ変更（T値）で音の長さを制御しているが、
音楽的に直感的な「音符の長さ」トークンを追加する余地がある。

```
L4  → 4分音符（以降の音符の長さを変更）
L8  → 8分音符
L16 → 16分音符
```

これにより `T120L8CDEF` のように「BPM120の8分音符でドレミファ」と書ける。
ただし、JSON Import機能で吸収できているため、優先度は低い。

## AI API直接呼び出し（Phase 3）

UIにAI APIを直接統合し、自然言語で作曲指示できるようにする。
JSON Import/Exportで十分に機能している場合は不要。
