MYNT MIDI - 機能追加予定（要望リスト）
===

```
Create : 2025-04-25
```

# 要望一覧

| # | 機能 | 説明 | 優先度 |
|---|---|---|---|
| 1 | トリム機能 | 再生範囲の開始・終了位置を指定して、その範囲のみ再生・エクスポートできるようにする | 高 |
| 2 | 停止ボタン | 再生を停止してタイムバーを先頭に戻す（現在は再生/一時停止のトグルのみ） | 中 |
| 3 | ループ再生 | 指定範囲またはタイムライン全体をループ再生する | 中 |
| 4 | エクスポート機能 | MIDI文字列をファイルとして保存・読み込みできるようにする | 中 |
| 5 | 音符の削除 | エディタ上の音符を右クリックまたはDeleteキーで削除 | 中 |
| 6 | 音符のリサイズ | 音符の長さ（duration）をドラッグで変更できるようにする | 低 |
| 7 | Undo/Redo | エディタ操作の取り消し・やり直し | 低 |
| 8 | テンポ表示 | タイムライン上にテンポ変更ポイントを可視化 | 低 |
