# 改善ポイント

## 操作性

1. **複数ノートの範囲選択**
   現在は1つずつしか選択できない。ドラッグで矩形選択、Shift+クリックで追加選択ができると、まとめて移動・削除・コピーが可能になる。

2. **コピー＆ペースト**
   選択したノートを Ctrl+C/V で複製。フレーズの繰り返しを作るのが格段に楽になる。

3. **スナップのグリッド切替**
   現在は固定グリッドだが、4分音符/8分音符/16分音符/フリーなどを切り替えられると配置精度が上がる。

4. **ノートのリサイズ時にカーソル変更**
   右端にホバーした時に `col-resize` カーソルを表示して、リサイズ可能であることを視覚的に示す。

---

## 再生・音源

5. **再生停止時にカーソル位置を保持**
   現在は停止するとカーソルが止まった位置のままだが、「停止で先頭に戻る」「一時停止で位置保持」を分けると使いやすい（Play/Pause/Stop の3状態）。

6. **Web Audio の音源改善** ✅ 実装済み
   現在は単純なオシレーターのみ。ADSR エンベロープ（アタック・ディケイ・サステイン・リリース）を追加するだけで音質が大幅に改善する。特にリリースがないので音がブツ切りになっている。

   **実装内容:**
   - `MidiPlayer._getEnvelope(oscType)` でオシレータタイプ別の ADSR パラメータを定義
   - `_schedule()` 内で各ノートに Attack → Decay → Sustain → Release のゲインカーブを適用
   - `startNote()` / `stopNote()` にも Attack + Release を適用（キーボードクリック時）
   - ノート長が短い場合は各フェーズを自動的に縮小して破綻しないよう調整

   **オシレータ別パラメータ:**
   | タイプ | Attack | Decay | Sustain | Release |
   |--------|--------|-------|---------|---------|
   | sine | 50ms | 100ms | 70% | 150ms |
   | triangle | 40ms | 80ms | 75% | 120ms |
   | sawtooth | 10ms | 100ms | 60% | 100ms |
   | square | 10ms | 80ms | 65% | 80ms |

7. **MIDI エクスポート**
   標準 MIDI ファイル (.mid) への書き出し。Web MIDI API や手動バイナリ生成で実現可能。他の DAW で使えるようになる。

   **実装メモ（見積もり: 1〜2時間）:**
   - `MidiParser.get_code()` の出力から SMF バイナリを手動で組み立てる
   - Format 0（単一トラック）で十分。マルチレイヤーなら Format 1 も検討
   - 可変長数値（VLQ）エンコードが必要（ロジック自体は20行程度）
   - 新規ファイル1つ（100行程度）+ エクスポートボタン追加

   **制約:**
   - ADSR エンベロープは MIDI ファイルに反映されない（MIDI は Note ON/OFF のみ、音色は再生側の責任）
   - オシレータタイプの情報は失われる（GM音色に近いものを Program Change で指定する程度）
   - 独自記法の `~`（フェードアウト）は MIDI に直接対応する概念がない（CC#7 で近似可能）

## データ管理

8. **プロジェクト単位の保存**
   現在は localStorage に1つの状態しか保存できない。プロジェクト名を付けて複数保存・切替できると便利。

9. **レイヤーの並び替え（ドラッグ＆ドロップ）**
   レイヤーが増えた時に順序を変えたい。

10. **インポート機能の強化**
    標準 MIDI ファイルの読み込み。sample/ にある JSON 形式からの自動変換。

---

## UI/UX

11. **ピアノロールのズーム（縦方向）**
    現在は横方向のスケールのみ。キーの高さを変えられると広い音域を俯瞰できる。

12. **再生位置の自動スクロール** ✅ 実装済み
    再生中にタイムバーが画面外に出たら自動追従する。

    **実装内容:**
    - `play_control` のアニメーションループ内で `_autoScroll(left)` を毎フレーム呼び出し
    - タイムバーが表示領域の右端80%を超えたら、左から30%の位置に来るようスクロール
    - ループで先頭に戻った時も追従
    - startボタン押下時も画面を先頭にリセット

13. **ダークモード**
    CSS変数ベースなので比較的簡単に実装可能。

---

## コード品質

14. **`main.min.js` の削除または自動ビルド**
    手動で作られた minified ファイルがソースと乖離している。ビルドツール（esbuild など）を導入するか、削除して `main.js` を直接使う。

15. **イベントハンドラの整理**
    `window` に直接登録されたイベントが複数箇所に散らばっている。イベントバスやコントローラーに集約すると見通しが良くなる。

---

## 優先度

| 優先度 | 項目 | 理由 |
|--------|------|------|
| 高 | 1. 範囲選択 | 操作の基本。これがないと編集効率が低い |
| 高 | 6. ADSR エンベロープ | 音の印象を大きく改善。実装コストも低い |
| 中 | 2. コピー＆ペースト | 範囲選択と組み合わせて効果を発揮 |
| 中 | 5. Play/Pause/Stop | DAW的な操作感に近づく |
| 中 | 12. 自動スクロール | 長い曲の編集時に必須 |
| 低 | 残り | あると嬉しいが現状でも使える |
