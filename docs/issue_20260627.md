# issue_20260627

作成日: 2026-06-27
対象: mynt_midi のツール本体機能と API モジュールの差分

## 概要

MIDI ツール本体に追加された機能に対して、API モジュールおよび API マニュアルの追随が一部不足している。
特に、Layers v3.0 の再生不整合が実運用上の主要な不具合となっている。

## Findings（重要度順）

### 1. 重大: Layers v3.0 が API で再生できない

- 症状
  - `playJson()` に `format_version: "3.0"` + `layers` を渡すと、単一 JSON_Format 側の検証に落ちてエラーになる。
  - 代表エラー: `JSON_Format must contain "bpm" and "notes" fields`
- 原因
  - API 側の分岐が `format === '2.0'` のみ Layers 扱い。
  - フォーマット判定は `detectFormat()` で `3.0` を返すため、分岐不一致が発生。
- 影響
  - ツール本体が生成する現行フォーマット（3.0）を API 経由で外部再生できない。
- 関連ファイル
  - [src/js/api/mynt-api.js](src/js/api/mynt-api.js#L231)
  - [src/js/midi/json-converter.js](src/js/midi/json-converter.js#L322)
  - [sample/コイン.json](sample/%E3%82%B3%E3%82%A4%E3%83%B3.json)

### 2. 高: API マニュアルが Layers 2.0 固定説明のまま

- 症状
  - ドキュメントが `format_version: "2.0"` 前提で記述されている。
- 原因
  - ツール本体の 3.0 運用への更新がマニュアルへ反映されていない。
- 影響
  - 外部利用者が 2.0 形式で実装しやすく、現行データとのミスマッチが起きる。
- 関連ファイル
  - [docs/api-manual.md](docs/api-manual.md#L420)

### 3. 中: Layers 再生時に PlayOptions の一部が実質未適用

- 症状
  - `playJson(layers, options)` で指定した `oscillatorType` / `volume` が Layers 再生時に反映されない。
- 原因
  - API は Layers 再生で `MidiPlayer.playLayers(layerData.layers)` を直接呼び、`options` をレイヤー設定へ反映していない。
- 影響
  - 単一 JSON_Format と Layers_JSON でオプション挙動が揃わない。
- 関連ファイル
  - [src/js/api/mynt-api.js](src/js/api/mynt-api.js#L244)
  - [docs/api-manual.md](docs/api-manual.md#L98)

### 4. 中: ツール本体にある offset 再生機能が API で未公開

- 症状
  - ツール本体はタイムバー位置からの途中再生（offset）に対応しているが、API では指定不可。
- 原因
  - API 公開メソッドに offset パラメータが存在しない。
- 影響
  - 外部ゲーム側で「任意位置から再生開始」ユースケースを満たしにくい。
- 関連ファイル
  - [src/js/controller/controls.js](src/js/controller/controls.js#L202)
  - [src/js/midi/player.js](src/js/midi/player.js#L152)

### 5. 低: 単音試聴系 API（start/stop note）が未公開

- 症状
  - 再生エンジンには単音開始・停止 API があるが、外部公開の `MyntMidi` から呼べない。
- 原因
  - API ファサードに公開メソッドが存在しない。
- 影響
  - ゲーム側のキー押下連動 SE（押下中のみ再生）の実装がしづらい。
- 関連ファイル
  - [src/js/midi/player.js](src/js/midi/player.js#L78)
  - [src/js/midi/player.js](src/js/midi/player.js#L119)
  - [src/js/api/mynt-api.js](src/js/api/mynt-api.js#L127)

## 推奨対応順

1. `playJson()` の Layers 判定を 3.0 対応に修正（最優先）
2. API マニュアルを 3.0 運用へ更新（例とスキーマ説明を改定）
3. Layers 時 `options` の適用仕様を決めて実装と文書を統一
4. 必要に応じて offset 再生オプションを API へ追加
5. 必要に応じて単音試聴 API を公開

## 補足

今回のサンプル不具合（coin-play-button）は 1 の分岐不一致が直接原因。
サンプル実装側の呼び出し方法自体は API 仕様に対して妥当。
